# OpenClaw AI Ops Agent 安全策略

## SSH 安全

1. **密钥认证**：禁用 SSH 密码登录，仅允许通过 SSH 密钥进行认证。
2. **最小权限**：`claw` 用户仅被授予运行必要命令的权限，避免过多的系统权限。
3. **禁用 root 登录**：系统禁用直接以 root 用户登录，所有高权限操作均通过 `sudo` 执行。

## sudo 权限

1. **限制 sudo 命令**：`claw` 用户的 sudo 权限仅限于以下命令：
    - `sudo systemctl`：用于服务管理。
    - `sudo docker`：用于容器操作。
    - `sudo journalctl`：用于查看日志。

2. **拒绝非法命令**：系统会拒绝任何未列入的命令，防止不必要的权限提升。

## 容器安全

1. **容器内部隔离**：OpenClaw 代理运行在 Docker 容器内，隔离宿主机环境，确保容器内运行的 Agent 不会直接影响宿主机系统。
2. **SSH 密钥管理**：所有与宿主机的 SSH 连接都通过加密密钥进行验证，避免密码泄露的风险。

## 传输加密

所有宿主机与容器之间的通信均通过 SSH 进行加密，确保数据在传输过程中不会被篡改或泄露。
