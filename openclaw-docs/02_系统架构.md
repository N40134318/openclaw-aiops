# 02 系统架构

## 整体架构

```
LLM Agent
   ↓
Tool Rules (AGENTS.md / TOOLS.md)
   ↓
Tool Execution
   ↓
vm-run wrapper
   ↓
SSH
   ↓
claw user
   ↓
sudo restricted commands
   ↓
host services
```

---

## vm-run 设计

由于 Agent 运行在 Docker 中：

```
container
   ↓
vm-run
   ↓
ssh
   ↓
host
```

vm-run 示例：

```
vm-run sys
vm-run docker
vm-run exec "date"
```

内部执行：

```
ssh claw@host "sudo docker ps"
```
