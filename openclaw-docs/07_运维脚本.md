# 07 运维脚本

## init-host.sh

功能：

1 创建用户

```
useradd claw
```

---

2 加入 docker 组

```
usermod -aG docker claw
```

---

3 安装 SSH key

```
~/.ssh/authorized_keys
```

---

4 写入 sudo 权限

```
/etc/sudoers.d/claw
```

允许：

```
docker
systemctl
journalctl
```

---

## verify-deploy.sh

验证运维链路：

```
container
 ↓
ssh
 ↓
claw
 ↓
sudo
 ↓
system
```

检查：

```
ssh whoami
docker ps
systemctl status docker
```
