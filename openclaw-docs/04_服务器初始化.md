# 04 服务器初始化

脚本：

```
prepare-ubuntu-for-openclaw.sh
```

作用：

### 1 配置 apt 源

支持：

- 清华 TUNA
    
- 中科大
    
- 阿里云
    

---

### 2 更新系统

```
apt update
apt dist-upgrade
```

---

### 3 安装基础工具

例如：

```
curl
wget
git
vim
tmux
htop
ripgrep
fd
nmap
tcpdump
```

---

### 4 安装 Docker

安装：

```
docker-ce
docker compose plugin
containerd
```

---

### 5 安装安全组件

```
ufw
fail2ban
```
