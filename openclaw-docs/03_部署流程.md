# 03 部署流程

新服务器部署推荐流程：

### Step 1 初始化服务器

```
sudo bash prepare-ubuntu-for-openclaw.sh
```

---

### Step 2 初始化宿主机权限

```
sudo bash init-host.sh claw_agent.pub
```

---

### Step 3 上传项目

```
scp openclaw.tar.gz server:/opt/
```

---

### Step 4 解压项目

```
tar xzf openclaw.tar.gz
```

---

### Step 5 启动服务

```
docker compose up -d
```

---

### Step 6 验证部署

容器中执行：

```
verify-deploy.sh
```
