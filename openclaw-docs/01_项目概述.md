# 01 项目概述

## 项目目标

构建一个 **AI Ops 运维 Agent 系统**，让 LLM 可以安全执行服务器运维操作。

核心目标：

- AI 可以执行运维任务
    
- 不给予 AI root 权限
    
- 所有操作经过工具层
    
- 系统具备可迁移性
    
- 运维操作可审计
    

系统能力：

```
LLM
 ↓
Agent Tools
 ↓
vm-run wrapper
 ↓
SSH
 ↓
Host User (claw)
 ↓
Restricted sudo
 ↓
System Services
```

---

## 系统设计原则

### 1 最小权限原则

AI 不直接获得 root 权限。

只允许执行：

- docker
    
- systemctl
    
- journalctl
    

---

### 2 工具化执行

AI 不直接执行 shell。

所有操作必须通过：

```
vm-run
```

---

### 3 隔离架构

Agent 在 **Docker 容器中运行**：

```
Container → SSH → Host
```

---

### 4 可迁移性

部署支持：

- 新服务器初始化
    
- 自动化脚本
    
- 容器部署
    
- 迁移 workspace
